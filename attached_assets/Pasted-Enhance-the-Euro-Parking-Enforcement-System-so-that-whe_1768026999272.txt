Enhance the Euro Parking Enforcement System so that
when MULTIPLE files are uploaded for the SAME CASE,
the system produces ONE unified analysis report.

====================================================
CORE REQUIREMENT
====================================================

When a user uploads:
- multiple images
- videos
- PDFs
- camera evidence
- manual uploads

ALL linked to the SAME caseId

➡ Analyse EVERYTHING together
➡ Generate ONE final case analysis
➡ Store ONE consolidated report

====================================================
CASE IDENTIFICATION (MANDATORY)
====================================================

Each evidence upload MUST include:
- caseId (string, UUID)
- siteId
- cameraId (optional for manual)
- source: "camera" | "manual" | "pdf"
- timestamp

If caseId already exists:
- DO NOT create new analysis
- Append evidence to existing case

CaseAnalysis

====================================================
ANALYSIS PIPELINE (CRITICAL)
====================================================

1️⃣ Trigger analysis ONLY when:
- User clicks "Analyse Case"
OR
- Auto-trigger when last file uploaded

2️⃣ Load ALL evidence for that caseId

3️⃣ Run AI analysis across ALL files:
- Merge detections
- Cross-validate findings
- Remove duplicates
- Resolve conflicts by confidence

====================================================
AI ANALYSIS RULES
====================================================

From ALL files combined, determine:

- Vehicle detected (yes/no)
- Vehicle type (EV / non-EV)
- Number plate (best confidence)
- Bay type (disabled / parent-child / EV / standard)
- Human detection:
    - adult
    - child
    - disabled badge visible
- Signage compliance (from PDFs/images)
- Time consistency (timestamps match offence window)

====================================================

Return ONE report per case:

{
