CONTEXT:
In the Evidence section, officers upload images/videos.
AI may analyse them, but FINAL responsibility must be human-verified.

GOAL:
Add a clear "Human Checked" section to each Evidence Case
to confirm whether the evidence is CORRECT or FAULTY for PCN issuing.

-----------------------------------
WHERE TO ADD
-----------------------------------
Evidence Page
(e.g. /evidence and /evidence/:id)

-----------------------------------
NEW SECTION UI
-----------------------------------
Add a new panel titled:

🧑‍⚖️ Human Verification

This section must appear AFTER evidence thumbnails
and BEFORE PCN decision actions.

-----------------------------------
VERIFICATION OPTIONS
-----------------------------------
Add 2 primary buttons:

✔ Evidence Correct (PCN Allowed)
✖ Evidence Faulty (PCN Must NOT Be Issued)

-----------------------------------
BEHAVIOUR RULES
-----------------------------------
1. Evidence Correct:
   - Confirms human agrees with analysis
   - Allows PCN workflow to continue
   - Shows green status badge:
     "Checked by Human – Valid"

2. Evidence Faulty:
   - Human confirms evidence is NOT reliable
   - PCN issuance must be BLOCKED
   - Show red status badge:
     "Checked by Human – Faulty Evidence"
   - Disable any "Issue PCN" buttons

-----------------------------------
MANDATORY COMMENT
-----------------------------------
If "Evidence Faulty" is selected:
- Require reason input (mandatory)

Examples:
- Vehicle not clearly visible
- Timestamp mismatch
- Bay markings unclear
- Wrong location
- Weather obscures evidence

-----------------------------------
BACKEND API
-----------------------------------
Create endpoint:

POST /api/evidence/:caseId/human-check

Payload:
{
  status: "valid" | "faulty",
  reason: string | null,
  checkedBy: userId,
  checkedAt: timestamp
}

DATABASE FIELDS

Store in evidence_case table:
