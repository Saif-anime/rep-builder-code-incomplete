   - caseId not saved when evidence is uploaded
   - mismatch between caseId vs evidenceId
   - incorrect route path or HTTP method
   - database query using wrong column or table
   - Prisma / ORM model mismatch
   - Case deleted or never created

   - A case is ALWAYS created before analysis runs
