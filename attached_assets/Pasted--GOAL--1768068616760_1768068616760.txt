Fix and implement the "Add Parking Bay" feature so that:
- Bays can be added successfully

====================================================
PART 1 – DATABASE (REQUIRED)
====================================================

Ensure a parking_bays table exists.

Create or update schema:

parking_bays
- id (uuid, primary key)
- site_id (uuid, foreign key → parking_sites.id, NOT NULL)
- name (varchar, NOT NULL)
- type (enum: STANDARD, PARENT_CHILD, DISABLED, EV)
- location (varchar, nullable)
- created_at (timestamp)
- updated_at (timestamp)

Add a unique constraint:
(site_id, name)

====================================================
PART 2 – BACKEND API
====================================================

Implement endpoint:

POST /api/sites/:siteId/bays

Request body:
{
  "name": string,
  "type": "PARENT_CHILD" | "STANDARD" | "DISABLED" | "EV",
  "location": string | null
}

Backend validation:
- siteId must exist
- name must not be empty
- type must be valid enum
- prevent duplicate bay names per site

On success:
201 Created
Return newly created bay object

On error:
400 → validation issue
409 → duplicate bay
500 → unexpected failure

Return structured JSON errors.
