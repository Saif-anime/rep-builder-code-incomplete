====================================================
TIME CALCULATION LOGIC (MANDATORY)
====================================================

For every case:

• Entry Time = earliest verified timestamp
• Exit Time = latest verified timestamp
• Parking Duration = Exit − Entry

Rules:
- Ignore gaps unless evidence shows vehicle left site
- Use multiple images to confirm continuity
- All timestamps must be normalized to site timezone

Example:
Entry: 10:12:08
Exit: 12:03:42
Duration: 1h 51m 34s

====================================================
MAXIMUM STAY RESOLUTION
====================================================

Resolve maximum stay as follows:

IF signage specifies max stay:
  use signage.max_stay_minutes

ELSE IF site regulations specify max stay:
  use site.max_stay_minutes

ELSE:
  mark max stay as UNKNOWN
  enforcement_decision = REVIEW_REQUIRED

Never display:
- absurd durations
- system uptime values
- placeholder math

====================================================
GRACE PERIOD APPLICATION
====================================================

If grace period exists:
effective_duration = parking_duration − grace_period

Grace period source:
- signage.grace_period
- else site.grace_period

====================================================
ENFORCEMENT HOURS VALIDATION
====================================================
