PROBLEM STATEMENT
====================================================
When uploading a signage inspection PDF, the API endpoint:

POST /api/signage-inspections/parse-pdf

returns:
500 Internal Server Error

Frontend shows:
"Failed to process PDF"

Network tab confirms:
- Request reaches server
- Server crashes during PDF parsing

====================================================
ROOT CAUSE ANALYSIS REQUIRED
====================================================
Investigate and FIX all of the following:

1. Multer / file upload middleware not configured correctly
2. PDF file not accessible via req.file
3. Buffer vs file-path mismatch
4. pdf-parse or pdfjs usage throwing uncaught exception
5. Missing try/catch and structured error response
6. Backend returning 500 instead of validation errors

- Accept only application/pdf
- Max file size: 10MB

  buffer,
  size
}

----------------------------------------------------

✅ Wrap PDF parsing in SAFE try/catch

- NEVER allow unhandled promise rejection
- Return 400 for invalid PDFs

- Return 500 ONLY for true server failures

----------------------------------------------------

✅ Use stable PDF parser

Implement pdf-parse safely:

- Validate buffer exists
- Catch parsing errors
- Log parser errors clearly
- Return extracted text as string

----------------------------------------------------

SUCCESS (200):
{
  success: true,
  extractedText: "...",
  mappedFields: {...}
}

FAILURE (400/422):

  success: false,
