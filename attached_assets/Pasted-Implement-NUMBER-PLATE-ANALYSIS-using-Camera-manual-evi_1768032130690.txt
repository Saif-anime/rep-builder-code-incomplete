Implement NUMBER PLATE ANALYSIS using:
- Camera / manual evidence uploads
- YOLOv8 (or ANPR OCR)
- DVLA Vehicle Enquiry API

====================================================
PRIMARY OBJECTIVE
====================================================

Whenever evidence is uploaded (image or video):

1️⃣ Detect vehicle number plate from evidence
2️⃣ Extract registration number
3️⃣ Call DVLA Vehicle Enquiry API
4️⃣ Store and display full vehicle details
5️⃣ Link results to the CASE (not individual file)

====================================================
INPUT SOURCES
====================================================

Evidence sources:
- Manual uploads (images/videos)
- Camera ANPR feeds

====================================================
PLATE DETECTION PIPELINE
====================================================

For EACH evidence file:

IMAGES:
- Run YOLOv8:
  - Detect vehicle
  - Detect number plate region
- Crop plate region
- Run OCR (Tesseract / PaddleOCR / EasyOCR)

VIDEOS:
- Extract frames (1 fps or motion-based)
- Run same pipeline per frame
- Select highest confidence plate

====================================================
PLATE NORMALISATION
====================================================

Before API call:
- Uppercase text
- Remove spaces
- Remove non-alphanumeric characters

Example:
"ab cd 123 de" → "ABCD123DE"

CASE-LEVEL STORAGE (MANDATORY)
====================================================

CaseVehicle

CONFIDENCE RULES
====================================================

- If plate detected in multiple files:
  - Require match consistency
  - Increase confidence
- If conflicting plates:
  - Flag for manual review
  - Do NOT auto-decide

UI REQUIREMENTS
====================================================

- Show detected registration

ERROR HANDLING
====================================================
